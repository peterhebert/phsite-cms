A note on icons included:

Most of these icons are the bookmark icon for the appropriate site (favicon.ico), converted to 8-bit PNG format with alpha transparency. These can be found in the 'favicons' folder.

Icons I have designed are in the 'peter-hebert' folder.
The icons can be used free for any personal or commercial projects.

If the icons are from another collection, I have included them in a subfolder with attribution and license terms in a text file named 'license-xxx.txt'.

Finally, other icons that I do not know the source for are found under 'other'.
